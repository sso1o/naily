# 구현 상태와 검증 기록

기준일: 2026-10-21 (Asia/Seoul). 이 파일은 현재 포트폴리오 사본의 검증 기준입니다. docs의 다른 과거 개발 기록에 적힌 미커밋 상태나 메모리 전용 설명과 구분합니다.

## 이번 보완

- 예약 디자인과 샵의 매칭, 유효 미래 날짜·시간, 같은 샵 또는 같은 사용자의 시간 중복 검사
- 예약 내역 취소, 샵별 승인·방문 완료, 종료 상태 재전이 거절
- 게시글·댓글·투표·반응·관심 샵·디자인·팔로잉·프로필·문의의 기기 저장
- 샵 관리 카드의 화면 연결, 가격·공지·이달의 아트 수정과 대표 디자인 지정
- 실제 선택한 저장 목록/활동 표시와 내 예약 상태 알림
- 선택 미디어의 영구 URI 변환, 새로고침 후 글 복원
- 미사용 패치 제거, 표준 테스트/빌드 명령과 GitHub Actions 추가

Node 24.14.1. 단위 테스트 중 일부는 React/네이티브와 사진 선택기를 모킹합니다. 모든 버튼·기기 조합의 E2E 완료를 뜻하지 않습니다. Android/iOS 실기기·사진 권한·키보드·네이티브 미디어 재생과 저장은 이번에 직접 검증하지 않았습니다.

## 제품 범위

단일 기기 로컬 체험 앱입니다. 실제 샵 접수·서버 인증·결제·다중 사용자 동기화·신고 운영·외부 푸시는 미연동입니다. 관리자 미리보기는 보안 경계가 아니며, 리뷰 본문은 샘플이며 샵 답변을 저장할 수 있습니다. 거리와 홈 프로모션/집계도 예시입니다.

웹 localStorage의 용량과 브라우저 정책에 따라 저장이 실패할 수 있습니다. 선택 파일은 웹에서 파일별 2MB 제한을 두고 데이터 URL로 보관하며 네이티브에서는 앱 문서 디렉터리에 복사합니다. 게시 전 임시 초안의 자동 복구는 제공하지 않고 화면 이탈 확인을 사용합니다.
