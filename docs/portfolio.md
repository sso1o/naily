# 포트폴리오 설명

## 프로젝트 소개

Naily는 네일 디자인 탐색에서 샵 비교·예약 체험·커뮤니티 작성까지 이어지는 Expo/React Native 개인 앱입니다. AI 코딩 도구를 활용해 전체를 진행한 바이브코딩 프로젝트입니다.

## 보여줄 수 있는 역량

- TypeScript 모델과 Expo Router를 사용한 다중 화면 연결
- 디자인·샵·날짜·예약 상태의 일관성 및 로컬 중복 예약 방지
- 블록형 글 편집, 선택 범위 서식, 사진 레이어·제스처·undo/redo
- 상세/목록 간 반응 상태 공유와 새로고침 후 복원
- 실패·취소·빠른 중복 입력·이탈 같은 예외 흐름 검사

## 이력서 문장

AI 코딩 도구를 활용해 Expo·React Native·TypeScript 기반 네일 탐색 및 커뮤니티 앱을 개인 프로젝트로 개발했습니다. 검색·예약 체험·블록형 글쓰기·사진 꾸미기·기기 저장을 연결하고, 예약 상태 전이와 재접속 데이터 유지, 편집기 조작을 테스트했습니다. 실제 샵 접수·결제·다중 사용자 서버는 연동하지 않은 로컬 체험 버전입니다.

다운로드 수·실사용자 수·매출·출시 실적은 주장하지 않습니다.
